AI Systems Built
CodeMas — AI Grading & Detection Engine
Django · Celery · GPT-4o-mini · TF-IDF · SSE
Real-time coding exam platform · 10,000 concurrent students · 5 AI agents in production
  • Rubric Scoring Agent — async Celery task scores every submission on 4 dimensions (correctness, code quality, approach, edge cases), each 0–2 with a per-dimension justification. Fires after result delivery; never on the hot path. Idempotent: safe to retry without double-scoring.
  • Socratic Hint Agent — for failed submissions, generates a pedagogical nudge (1–3 sentences) pointing at the concept without revealing the answer. Stores once, survives page refresh. Skips gracefully if no API key is set.
  • Plagiarism Explanation Agent — after TF-IDF cosine similarity flags a code pair, GPT writes a trainer-facing evidence brief citing specific code overlaps, behavioural signals, and a low/medium/high confidence rating. Evidence for the human reviewer — never a verdict.
  • Exam Summary Agent — aggregates per-submission rubric scores and pass/fail outcomes into a 3–4 sentence personalized performance narrative per student per exam. Generated lazily on first view, cached permanently.
  • AI Exam Generator — trainer-facing tool: given topic, language, difficulty, and question count, returns a complete draft exam (questions + 3 test cases each). Human-in-the-loop: draft returned for review, never auto-persisted.
  • 3-layer detection engine — behavioural scoring (paste ratio 0.40, speed anomaly 0.30, tab switches 0.15, attempt surprise 0.15) → TF-IDF + cosine similarity O(K×N) suspect scan → GPT explanation layer with full ReviewAuditLog trail and versioned PlagiarismPolicy.
0.1% DEV — RAG Learning Assistant
FastAPI · text-embedding-3-small · gpt-4.1-mini · React 18
Ed-tech course platform · 8 deep CS fundamentals courses · RAG grounded strictly in proprietary transcripts
  • Custom chunker — 180-word sliding windows (35-word overlap, step=145) over transcript JSON, metadata-tagged with course ID, lecture name, and timestamp range per chunk.
  • In-memory vector store — pure Python cosine similarity, zero NumPy or FAISS. embed_many() batch-embeds at startup via text-embedding-3-small. FAISS/Pinecone swap is a one-file change to vector_store.py.
  • Hybrid re-ranking — top 8 semantic candidates re-scored by max(semantic, jaccard_lexical) with stop-word filtering; threshold gate at 0.15 returns a canned message with no LLM call (saves cost, blocks hallucination).
  • Source-linked answers — gpt-4.1-mini citations map to exact lecture and timestamp; React SourceCard components deep-link into the video player at the cited second via ?t=seconds.
