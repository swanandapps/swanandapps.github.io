About me

Building Easy solutions
for Difficult problems.

I'm a senior full stack and AI engineer who co-founded the01.dev, an AI-powered ed-tech platform where I led a 2-engineer team and owned architecture end-to-end. That included a PDF-to-lesson multi-agent pipeline using LangChain and Mastra with Planner-Executor and Supervisor-Worker patterns, a production RAG assistant backed by pgvector with HNSW indexing and hybrid cosine + BM25 retrieval, and an adaptive practice engine with a concept knowledge graph. Before that, I joined Masai School as one of the first engineers reporting directly to the CTO.

At Masai I built CodeMas — a real-time coding assessment platform handling 10,000 concurrent users and ~10K submissions/sec at deadline bursts via AWS Lambda + SQS + SSE. The plagiarism engine went from detecting 5% of cheating cases to 95% — a 19× lift — by reframing the problem from "are two submissions similar" to "did this student write this." I also created Kalaam, India's first Hindi programming language, which earned me a TEDx Bangalore talk ("Why we should be able to code in our own languages"), 500+ monthly users, and a 10+ contributor open-source community.

I write too. Published in Better Programming, three articles on HackerNoon, and featured on InfoQ. I care about systems that work under pressure, products that reach people who are usually left out, and open source that actually gets used.

01 / 04
CodeMas
Production
Real-time coding assessment platform · 10K concurrent users · 10K submissions/sec · built at Masai School

Joined as one of the first engineers reporting directly to the CTO. Infrastructure: code submit → AWS Lambda + SQS + Docker sandbox → SSE push, sub-10s results at ~10K submissions/sec deadline bursts.

AI features — 5 agents in production:

  • → Exam Generator — GPT drafts complete exams (questions + test cases) from a topic and difficulty with human-in-the-loop review before persistence. ~80% faster exam creation.
  • → Rubric Scoring Agent — async GPT grades every submission on correctness, code quality, approach, and edge cases (0–2 each) with per-dimension justifications. Consistent feedback at scale across 10K+ submissions with zero trainer review overhead.
  • → Socratic Hint Agent — for failed submissions, generates a pedagogical nudge pointing at the concept without revealing the answer, isolated from the delivery path. Students self-correct without trainer intervention.
  • → Trainer Dashboard Agent — AI-generated cohort summaries, per-student performance narratives, and exam insights. Replaced manual spreadsheet reporting entirely — hours of post-exam analysis eliminated.
  • → Plagiarism Engine — two-layer detection: behavioural signals (paste ratio, speed anomaly, tab switches) + TF-IDF cosine similarity. Reframed the problem from "are submissions similar" to "did this student write this." Detection rate: 5% → 95% — a 19× lift.

Kalaam
npm · v2.3.3
India's first Hindi programming language · TEDx Bangalore · 500+ monthly users · 10+ contributors

Hand-written lexer and instruction-sequence interpreter, published as an npm package (kalaam-core), built for students who have no laptop and intermittent internet.

  • → Multi-language Architecture — 5 languages (Hindi, Marathi, Bengali, Telugu, Odia) supported via centralized keyword configuration; adding a new language is one map entry, zero parser changes. Infinitely extensible without touching the interpreter core.
  • → Fully Offline PWA — zero API calls, service-worker cached, runs entirely in the browser on a budget Android phone with no internet. Reaches students in tier-3 cities who are locked out of every other coding tool.
  • → Open-source Community — led 10+ contributors through structured releases with clear contribution guidelines and staged reviews. 500+ monthly active users on kalaamlang.in.
  • → TEDx Bangalore — invited to speak on "Why we should be able to code in our own languages." Recognised as a meaningful intervention in CS access for non-English speakers in India.
